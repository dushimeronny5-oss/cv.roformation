## 🛠️ Stack Technique

- **Structure** : HTML5 sémantique, optimisé pour le référencement naturel (SEO).
- **Styles** : Vanilla CSS3 moderne avec variables de design, animations fluides, typographie *Space Grotesk* & *Plus Jakarta Sans*, responsive design (mobile, tablette, desktop) et feuille de style dédiée à l'exportation PDF (`@media print`).
- **Logique** : JavaScript Vanilla (ES6+) pour le filtrage dynamique des compétences, la copie d'email en un clic, la préparation du PDF et le **Mode Édition en direct** avec sauvegarde locale (`localStorage`).

## 🌐 Déploiement GitHub Pages

Ce site est statique et prêt à être hébergé gratuitement en 1 clic sur **GitHub Pages** :
1. Dans votre dépôt GitHub `cv.roformation`, rendez-vous dans l'onglet **Settings** (Paramètres).
2. Cliquez sur **Pages** dans le menu latéral gauche.
3. Sous **Build and deployment > Branch**, sélectionnez la branche `main` et le dossier `/ (root)`.
4. Cliquez sur **Save**. Votre CV en ligne sera accessible publiquement à l'adresse :
   `https://dushimeronny5-oss.github.io/cv.roformation/`
